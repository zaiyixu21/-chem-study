# 知检 CHEMLAB

面向化学检验员理论复习的轻量网页软件，完整导入提供的 2026 年 9 月 18 日修订题库，共 505 道题。浅色 / 深色外观，适配手机和电脑。

## 已实现功能

- 学习概览：已练题目、最近一次作答正确率、错题数量、今日练习、近 7 天统计。
- 顺序练习与随机练习：题型、难度、错题、收藏、未练题筛选，题目导航、换题和刷新题目。
- 单选、多选、判断三类题型；多选必须全部选对。
- 提交后显示参考答案；单独查看答案不计入作答统计。
- 自动错题本：答错收录，重新答对后移出。
- 收藏、全文搜索、分页题库。
- 限时自测：自定义题型、难度、题量与时长，随机抽题无重复，答题卡跳转。
- 考试刷新恢复、绝对时间倒计时、时间结束自动交卷。
- 考试报告、逐题对照、只看错题、重练本场错题、最近 30 次考试记录。
- 本机保存进度；支持 JSON 备份导出与导入。
- 键盘快捷键：A–G 选项，判断题 A / B，左右切题，Enter 提交 / 下一题，/ 搜索。

## 立即使用

用现代浏览器打开 `dist/index.html` 即可。无需安装依赖、数据库或服务端。也可以使用发行包中的单文件 HTML。

本机打开时，一些浏览器会限制文件页面的本地存储或下载功能。通过 GitHub Pages 的 HTTPS 地址使用可以获得更稳定的进度保存体验。

## 部署到 GitHub Pages

1. 新建一个仓库，例如 `chem-study`。若使用 GitHub Free，选择公开仓库以使用 Pages。
2. 把本项目的文件完整上传，保留 `dist`、`tests` 和 `.github/workflows/pages.yml` 的目录结构。
3. 进入仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
4. 将文件推送到 `main` 后，自动运行检查并部署；也可以在 Actions 页手动运行 **Deploy CHEMLAB to GitHub Pages**。
5. 以 Actions 成功结果返回的 Pages 地址为准。

部署说明对应 GitHub 官方文档：
https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

应用全部使用相对资源路径和 hash 路由，兼容仓库子目录。发布的静态页面中包含题目和参考答案；这是个人学习软件，不用于需要服务端保密答案的正式考试。

## 数据与评分口径

- 单选题 211 道、多选题 166 道、判断题 128 道，无题目重复、无缺失参考答案。
- 题目、选项、难度与参考答案均保留源文件内容。统一了“单选 / 单选题”等题型标记以及判断题的 √ / × 交互格式。
- 原题库未提供解析，因此只展示原始参考答案，不生成或编造解析。
- 自测满分 100，按题目等分，漏答与多选漏选均不得分。60 分为软件的练习达标线，不代表正式考试规则。
- 已练题数按不同题目计数；今日练习和趋势按提交次数计数；当前正确率按每道已练题目最近一次作答计算。
- 考试只在交卷后计入学习记录和错题本。未答题在考试报告中记为错误。
- 进度仅保存到当前浏览器，不会自动跨设备同步；建议定期导出备份。

## 更新题库

保留原表 A–K 列结构，在项目根目录运行：

```bash
python3 tools/import_bank.py /path/to/题库.xlsx
```

当前导入程序对这份 505 道题的数据做了完整性断言。更新为不同题量时，应同步更新断言、界面数量和测试，避免展示不一致。

## 验证

```bash
node --check dist/app.js
node --check dist/core.js
node --check dist/data.js
node --test tests/core.test.cjs
```

8 项自动检查覆盖题库完整性、三种题型评分、多选完整匹配、随机无重复、未答题计分、计时边界和错题重做。

运行时无第三方依赖，无远程字体或统计追踪。源文件位于 `dist/`；导入脚本位于 `tools/`。
